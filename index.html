Stash Media Library bydesign

A personal media-library integration that uses rclone to read media files from the owner's Google Drive for use in a private Stash library.

Purpose and access

The integration is for the owner's personal use. Its Google Drive access is read-only: it reads file information and media content to browse and organize the private library. It does not provide a public file-sharing service.

About this website

This public website provides application information and a privacy policy. It has no sign-in form, does not connect to Google Drive, and does not display the private library.

This is an independent personal integration, not a Google product.
