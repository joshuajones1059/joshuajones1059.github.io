Stash Media Library bydesign

Privacy policy

Effective date: November 13, 2026.

This policy describes the personal, read-only Google Drive integration called Stash Media Library bydesign, which uses rclone with a private Stash media library.

Google Drive data accessed and used

With the owner's authorization, rclone can read Google Drive file information, such as names, folder relationships, file types, sizes, and modification dates, and read media content. This access is used to make the owner's media available to their private library. A read-only Drive permission can allow access beyond the folder currently used by the library; a configured folder is not a separate Google permission boundary.

The integration uses read-only access and does not use Google Drive access to upload, edit, or delete the owner's Drive files.

Storage and retention

Google Drive remains the source of the media. The private environment running rclone and Stash may retain downloaded or cached media, library metadata, thumbnails, previews, and operational logs as part of normal operation. OAuth access and refresh tokens are held in the private rclone configuration so it can maintain authorized access.

Private copies and derived library data remain until removed by the owner or cleared by the configured software. Revoking Google access stops future authorized access but does not automatically delete existing private copies, caches, or metadata.

Sharing and other uses

The integration is for the owner's use and does not publish Drive files or library records on this website. Google data is not sold, used for advertising, or used to train generalized artificial intelligence or machine-learning models by this integration. Data is processed by Google and the private computing or hosting services used to run the integration as needed for its operation.

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Public website

This informational website is hosted by GitHub Pages. It contains no analytics scripts, advertising, forms, or Google sign-in flow. It does not receive OAuth tokens or Drive files. GitHub may process visitor information such as IP addresses and request details to operate and secure its hosting service, under the GitHub General Privacy Statement.

Control and revocation

The owner can revoke this application's access in Google Account connections. The owner can separately remove the rclone authorization and delete retained data in the private library environment. Removing a private cached copy does not require deleting the Drive original.

Questions and changes

This integration is operated by its owner for personal use and does not accept public account registrations. The owner manages its privacy settings through their Google Account and private library configuration. This policy will be updated if its data practices change.
